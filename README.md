# HelloR

> 分享实用的 R 语言包、教程、博文等，记得收藏，用到再翻看。  
> 兴趣是最好的老师，**HelloR** 帮你更快摸到 R 的乐趣！

灵感来自 [HelloGitHub](https://github.com/521xueweihan/HelloGitHub)。英文社区已有 [R Weekly](https://rweekly.org/)（偏博客）；**HelloR** 专挑可点仓库，中文短介绍。

仓库：[shalom-lab/hello-r](https://github.com/shalom-lab/hello-r)

## 硬规矩（每条条目必须有）

1. **可点链接**：仓库主页必给；有文档站再加「文档」链接  
2. **配图**：须体现产品特殊界面/输出的截图或文档示例图；禁止 GitHub Open Graph / social preview 那种仓库名片图。图片放在 `images/期号/`  
3. **文风**：`编号、[仓库名](url)：一句话钩子。` + 两三句说明  
4. **每期标题**：形如 `# HelloR 第001期｜……`（要有「第」；期号三位；后接概括看点）。**微信公众号标题硬上限 64 字**（含标点与英文）；建议 **≤28 字**。README 目录表同步。  
5. **公众号开场/落款**：面向公众号「R语言与可视化」。开头用第一人称（你好、欢迎……），点出 HelloR 与公众号；文末写欢迎关注/订阅「R语言与可视化」。

没有图或没有链接的条目，不进当期。

条目以实用的 R 语言包、教程、博文等为主，方便收藏备用；不绑死 GitHub 或某一周刊/榜单；有可点链接与特色配图即可。

## 更新节奏

- **每周一**更新一期
